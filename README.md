# ⚡ Smart Energy Consumption, Prediction and Optimization

An intelligent Machine Learning-based Smart Energy Management System that predicts electricity consumption and detects abnormal energy usage patterns using advanced ML algorithms.

---

# 📌 Project Overview

Electricity demand is increasing rapidly, making efficient energy management essential. This project uses Machine Learning algorithms to:

- Forecast electricity consumption
- Detect abnormal power usage
- Improve energy efficiency
- Support smart decision-making
- Provide interactive visualization dashboards

The system combines:

- Random Forest for electricity prediction
- Isolation Forest for anomaly detection
- Flask backend
- React frontend dashboard

# 🧠 Machine Learning Algorithms Used

## 1️⃣ Random Forest

### Purpose
Used for electricity consumption forecasting.

### Why Random Forest?
- High prediction accuracy
- Handles nonlinear data efficiently
- Reduces overfitting
- Works well with large datasets

---

## 2️⃣ Isolation Forest

### Purpose
Used for anomaly detection in energy usage.

### Why Isolation Forest?
- Fast anomaly detection
- Efficient for large datasets
- Unsupervised learning approach
- Detects unusual energy patterns effectively

# ▶️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/smart-energy-management.git
```

## Navigate to Project

```bash
cd smart-energy-management
```

## Install Backend Dependencies

```bash
pip install -r requirements.txt
```

## Start Flask Server

```bash
python app.py
```

## Start Frontend

```bash
npm install
npm start
```
